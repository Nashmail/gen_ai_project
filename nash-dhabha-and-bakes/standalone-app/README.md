# Standalone app (one file)

`NASH-Dhabha-Masala-Mitra-app.html` is the whole website in a single file. No server is needed.

1. Download it and open it in **Chrome or Edge**.
2. Allow the microphone to talk to Masala Mitra and record chef notes.
3. Optional: tap **✦** in the chat header and paste a free Google Gemini key (https://aistudio.google.com/apikey) for Gemini-written answers.

Rebuild it from the source with `node scripts/build-artifact.js` (the output goes to `dist/`).
