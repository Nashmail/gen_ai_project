## [NASH Dhabha & Bakes: Masala Mitra](nash-dhabha-and-bakes/)

<img src="nash-dhabha-and-bakes/frontend/assets/logo-1200.png" alt="NASH Dhabha & Bakes" width="360">

Masala Mitra: a voice-enabled RAG chatbot waiter for NASH Dhabha & Bakes. It suggests dishes by mood, answers menu questions from the real menu, takes chef notes by voice, and tracks orders to the bill and payment. Node.js + Express backend, vanilla JS frontend, optional Google Gemini.

- Project, how it works and how to run it: [`nash-dhabha-and-bakes/README.md`](nash-dhabha-and-bakes/README.md)
- Test report (every scenario, with stored results): [`nash-dhabha-and-bakes/scenarios/REPORT.md`](nash-dhabha-and-bakes/scenarios/REPORT.md)
- LinkedIn video: [`nash-dhabha-and-bakes/video/`](nash-dhabha-and-bakes/video/)

Deploy the backend and website on Render with the root `render.yaml` (New → Blueprint). Tests run on every push via GitHub Actions.
